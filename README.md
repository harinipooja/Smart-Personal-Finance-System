# Pocketwise

A personal finance dashboard for tracking monthly income, expenses, budgets, and spending patterns.

## Features

- Add, edit, delete, search, and filter income and expense transactions.
- Review cash flow and category spending charts by month.
- Set category budget limits and monitor remaining budget.
- Export the selected month's transactions as CSV.
- Save transactions and budgets in browser local storage.
- Responsive layout for desktop and mobile screens.

The dashboard starts with sample data so the charts and budget views are populated. Data is stored only in the current browser and is not connected to a bank or synced between devices.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run lint
npm run build
```

## Stack

React, TypeScript, Vite, Recharts, and Lucide React.
